# Travail Pratique 3 - Programmation avancée en C++ pour l’ingénierie
### GIF-1003 - Hiver 2026

---

## Description du projet

Ce dépôt contient l’implémentation complète dans l'IDE NetBeans du **Travail pratique 3** du cours *Programmation avancée en C++ pour l'ingénierie*.
L’objectif principal est de développer une mini‑application de gestion d’immatriculation de véhicules de la SAAQ avec interface Qt.
